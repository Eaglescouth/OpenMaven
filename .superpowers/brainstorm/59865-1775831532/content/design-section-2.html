Design — Section 2: Mission Planning

D2: Mission Queue Panel & D3: Waypoint Route Editor — following the existing hook-per-feature pattern

D2 — Mission Queue Panel

A collapsible panel on the right edge of the map (above the strike log panel). Shows all queued and in-flight missions in order. Implemented as a pure React component — no new hook needed, it reads directly from sim.activeMissions and a new sim.missionQueue field that the backend already tracks.

D3 — Waypoint Route Editor

A new waypoint mode (alongside existing move mode). Activate via right-click context menu on a friendly asset: "Set Patrol Route". Click the map to place up to 5 waypoints — each rendered as a numbered dot connected by dashed blue lines. Confirm sends a sequence of move orders to the backend. Routes are stored in frontend state only (no new backend endpoint needed — we reuse the existing /simulation/move API sequentially).
