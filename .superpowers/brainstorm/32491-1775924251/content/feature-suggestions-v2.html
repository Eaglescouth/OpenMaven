What UI/UX feature should we build next?

Select one or more that interest you. Multi-select enabled.

A

Simulation Replay & Time Scrubber

Scrub backward/forward through battle history tick-by-tick. Snapshots asset positions at every N ticks. Pause live sim, rewind to before a strike, watch the kill chain frame-by-frame. Builds on the existing event timeline and useSimulation hook.

Scrubber bar on map · snapshot cache · post-mission debrief

B

Commander's Dashboard

New top-level tab — strategic overview without the map. Live BLUFOR vs REDFOR asset counts, missions launched/completed/aborted, kill/loss ratios, last 5 significant events, and ROE violation counts. All data already flows through useSimulation, so this is mostly a new view layer.

New nav tab · stat cards · faction bar chart · event feed

C

SIGINT / Comms Intelligence Feed

Surfaces the comms_intelligence Kafka topic in the UI for the first time. Live intercept stream: signal frequency, strength, geolocation estimate, confidence score. Intercepts near known REDFOR assets get a correlation badge. Map shows pulse rings at intercept locations.

Collapsible sidebar · Kafka Layer 1 data · map pulse rings

D

Alert & Notification Center

Currently all events are silent. Adds: (1) color-coded toast banners for high-priority events (red = asset lost, amber = ROE violation, green = mission success), and (2) a persistent notification tray (bell icon) so nothing gets missed. Clicking an alert zooms the map to the relevant asset.

Toast overlay · bell tray · severity levels · click-to-focus

E

ROE Policy Audit Log

Every OPA policy evaluation — ALLOWED or DENIED — logged with rule name, target, requesting unit, and timestamp. Filter by outcome, rule, or time range. Each entry expands to show the full Rego trace. Makes the policy engine transparent and auditable — core to OpenMaven's purpose.

Enhances Decisions tab · OPA trace · filter by rule/outcome

F

Prioritized Threat Ranking Panel

Sortable panel ranking all REDFOR assets by threat score: kill_prob × proximity_weight × asset_class_multiplier. Updates every tick. Clicking a row zooms the map and auto-populates the strike pairing panel. Closes a real workflow gap — right now target selection is entirely manual map scanning.

Collapsible panel · live sort · click-to-strike integration
