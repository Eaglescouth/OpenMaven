Deep Dive: Options B, C & D

B

Commander's Dashboard

A new top-level nav tab — strategic overview without touching the map. Four zones:

  • Faction Strength Bar — live BLUFOR vs REDFOR asset count, broken down by asset class. Shifts in real time as assets are destroyed.
  • Mission Stats — cards showing missions en route / completed / aborted, kill/loss ratio prominently displayed.
  • ROE Summary — total OPA decisions this session, ALLOWED vs DENIED split, most-fired policy rule.
  • Live Event Feed — last 10 significant events, same data as the timeline drawer but surfaced here without needing the map open.

All data already flows through useSimulation — zero new backend work. Purely a new frontend view.

New nav tab · stat cards · faction bar · event feed · frontend only

C

SIGINT / Comms Intelligence Feed

Surfaces the comms_intelligence Kafka topic in the UI for the first time — Layer 1 of the ingestion architecture becomes visible to the operator.

  • Signal Intercept Stream — live panel showing frequency/type (VHF, UHF, satellite), signal strength, confidence score, and geolocation estimate with margin of error.
  • Correlation Badges — intercepts geolocating within 30km of a known REDFOR asset get flagged with that asset's ID.
  • Map Pulse Rings — animated radar-ping rings at intercept locations on the map, distinct from asset markers.

Requires a new WebSocket endpoint on the backend to stream comms_intelligence events, plus a useSignalIntelligence hook on the frontend. Most technically involved of the three.

Collapsible panel · new WS endpoint · Kafka Layer 1 · map pulse rings

D

Alert & Notification Center

OpenMaven is currently completely silent — nothing announces itself. This adds two layers of awareness:

  • Toast Banners — transient notifications (4s fade) in the top-right, color-coded by severity: ■ Red = asset lost, ■ Amber = ROE denial / aborted, ■ Green = mission success, ■ Blue = new contact. Clicking zooms the map to that asset.
  • Notification Tray — bell icon in the header with a badge count. Opens a drawer with every alert from the session, newest first. Nothing gets missed even if you blink past a toast.

Lowest implementation complexity of the three — frontend only, consumes the existing simulation event stream, zero new backend work. Highest UX impact per line of code.

Toast overlay · bell tray · severity levels · click-to-focus · frontend only

Note: B and D pair naturally — both are frontend-only and share the "make simulation state visible" theme. C is the most powerful but needs backend work too.
